Case Study 01 • Agentic RAG

Enterprise IT Support: Agentic RAG Copilot

Tech Stack: LangGraph • Pinecone Vector DB • FastAPI • DuckDuckGo API • Render
Live Cloud Demo GitHub

The Problem

Enterprise IT helpdesks spend over 60% of engineering bandwidth resolving repetitive VPN, access control, and software configuration tickets. Static knowledge bases quickly become obsolete, and traditional linear RAG chains hallucinate during multi-step troubleshooting.

Key Architectural Decisions

  • StateGraph Multi-Turn Loop: Replaced rigid linear chains with a cyclic LangGraph state machine, allowing the copilot to re-query or ask clarifying questions when initial retrieval confidence is below 85%.
  • Hybrid Fallback Retrieval: Integrated Pinecone serverless vector search for proprietary docs with automatic fallback to live web querying for newly emerging OS/software bugs.

Architecture & Execution Flow

1
User Query Ingestion: Query rewriter extracts core technical entities and intent.
2
Hybrid Dense/Sparse Vector Search: Pinecone retrieves internal SOPs; evaluates relevance score.
3
LangGraph Reasoning & Guardrails: Verifies factuality, redacts internal PII, and validates resolution steps.
4
Automated Resolution / Escalation: Returns verified fix with source citations or creates escalation ticket.
99.4% Factual Precision
-65% Triage Resolution Time
<220ms Vector Retrieval Latency
*Methodology: Measured across 200 curated IT enterprise benchmark queries evaluated via RAGAS factual precision & LangSmith latency traces.
Case Study 02 • Multi-Agent Systems

Multi-Agent System: MCP, Supervisor & Human-in-the-Loop

Tech Stack: FastAPI • LangGraph • Model Context Protocol • Gemini 2.5 Flash • Docker
Live Cloud Demo GitHub

The Problem

Uncontrolled autonomous agents executing arbitrary tool operations present severe security and hallucination risks in enterprise settings. Single-prompt monolithic LLMs struggle to maintain focus across complex multi-domain operations.

Key Architectural Decisions

  • Standardized MCP Tool Interface: Adopted Model Context Protocol (MCP) to decouple tool definitions from the LLM core, establishing unified sandbox permissions.
  • Explicit Human Approval Node: Designed a dedicated interrupt checkpoint for high-stakes actions (database writes, email dispatches) requiring explicit operator confirmation.

Architecture & Execution Flow

1
Objective Ingestion: Master Supervisor decomposes complex goals into dependency sub-tasks.
2
Specialized Worker Routing: Distributes sub-tasks to Research, Code, or Analytical Worker agents.
3
MCP Server Sandbox: Tools execute within strict boundaries; logs full payload telemetry.
4
Human Review & State Commit: Operator inspects proposed changes before graph state write-back.
100% Audited Tool Traces
0 Unauthorized Actions
4 Specialized Agent Roles
*Methodology: Verified across 150 multi-step agent execution runs with Human-in-the-Loop sandbox checkpoints.
Case Study 03 • Deep Learning & Computer Vision

Deep Learning Malaria Parasite Detection & Diagnostics

Tech Stack: PyTorch • TensorFlow • ResNet50 • OpenCV • Streamlit Cloud
Live Cloud Demo GitHub

The Problem

Manual examination of microscopic Giemsa-stained thin blood smear slides is labor-intensive, slow, and susceptible to technician diagnostic fatigue in resource-constrained rural clinics.

Key Architectural Decisions

  • Transfer Learning with Residual Depth: Fine-tuned deep residual layers of ResNet50 while freezing base convolution filters to prevent overfitting on staining artifacts.
  • Dual-Head Softmax Confidence: Implemented entropy-based uncertainty thresholds that flag borderline cell slides for secondary laboratory review.

Architecture & Execution Flow

1
Microscopic Cell Slide Upload: Image normalization, color space balancing & artifact filtering.
2
ResNet50 Deep Feature Extractor: Residual bottleneck blocks extract high-level cellular morphology.
3
Dual-Head Classifier & Confidence Estimator: Generates probability distribution for Parasitized vs Uninfected.
4
Streamlit Diagnostic Brief: Generates instant patient diagnostic report with visual overlay.
97.2% Diagnostic Accuracy
<120ms Inference Latency
0.98 ROC-AUC Score
*Methodology: Evaluated on 27,558 Giemsa-stained thin blood smear cell images with 5-fold cross-validation.
